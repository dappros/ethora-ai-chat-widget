DEV entry (live from src/)

Compiled by Vite on the fly. No dist/, so you cannot be looking at a stale bundle here. Edit a file, save, the page reloads.

How to run

cd /Users/admin/Work/ethora/ai-assistant-ui
npm run dev
# then open the printed URL with /dev.html appended

Which page to use when

  • dev.html (this one): iterating on the UI. Always current.
  • local-test.html: testing the built bundle, with the XMPP debug harness. Needs npx vite build first.
  • dev-cdn-reference.html: the shipped production widget, for diffing against.
  • dev-launcher-preview.html: static launcher mockup, no backend.

Why python3 -m http.server showed old code

It is a plain static file server. It never runs TypeScript or Vite, it just hands over whatever is already on disk. local-test.html loads dist/ethora_assistant.js, so it shows whatever the last vite build produced, no matter how much src/ has changed since.
