Supported embed attributes (read by the current source)

data-app-idrequired, the Ethora app id
data-api-baseAPI base. data-api-url is an accepted alias
data-bot-namebot display name (alias data-bot-display-name)
data-bot-avatarimage URL, also replaces the launcher glyph
data-titleheader label, defaults to the bot name
data-greeting-title / data-greetingempty-state copy, rendered via noMessagesPlaceholder
data-disable-mediahide attach + mic, text-only composer. Default false
data-allow-fullscreenshow the expand control in the header. Default true
data-start-fullscreenopen expanded. Default false
data-launcher-iconcustom launcher glyph URL, contained not cropped
data-launcher-gradienttwo colours, e.g. 6e72fc,ad1deb. Default is the original violet gradient
data-flat-launcheruse the flat primary-color instead of the gradient. Default false
data-launcher-sizediameter in px. Default 56
data-launcher-glowpulsing glow. Default true
data-cta-textteaser above the launcher. Default "Ask me anything!", empty string disables
data-cta-delay / data-cta-sparklems before it appears (default 1200) and the leading ✨
data-greeting-messagestarter bubble: rendered as a bot message, never sent over XMPP. Falls back to the Agent's greeting from the server. Empty = none
data-hide-system-messagesfalse to show "X has joined"
data-primary-color / data-secondary-colortheme, bare hex accepted
data-icons-color, data-own-bubble-bg, data-other-bubble-bg, data-input-bgfine-grained colors
data-font-family, data-font-size, data-google-fonttypography
data-positionleft or right, default right
data-width / data-heightdocked panel size. Bare number = px; px % vw vh rem em accepted, e.g. 40%. Default 360px x 560px
data-expanded-width / data-expanded-heightsize when expanded, same units. Default 100% =true fullscreen
data-expanded-insetgap around the expanded panel. Default 0px: edge to edge, no radius, no shadow. Set 16px to float it
data-localeUI caption language. Defaults to the page's <html lang>, then the browser

Appearance keys are also overridable per-link via ?ethora-<key>=, e.g. ?ethora-primary-color=7c3aed&ethora-width=520. app-id, api-base and bot-id deliberately are not.

Rebuild required

The source now implements the composer toggle, the empty-state placeholder, the fullscreen control and the custom launcher icon, plus the fix for the bogus MAM history requests. dist/ in this repo predates all of that, so this page will not show them until you rebuild: 

cd ai-assistant-ui && npx vite build --minify false

Use npx vite build, not npm run build: the latter gates on tsc, which fails on pre-existing userLogin.user typing errors and leaves a stale dist/. Bump ?v= above afterwards.

Known issue this page detects

"Conference room does not exist" in Stanza errors is not your real room failing. It is five MAM get-history IQs sent to activeRoomJID@, rooms@, usersSet@, subscribedRooms@ and pushSubscriptionStatus@: rooms-slice root keys that leaked into the persisted rooms map and then had the conference domain appended to them. The real room joins fine alongside. Fixed in ethora-chat-component via toRoomJid(), which refuses to build a JID out of a non-room value.
